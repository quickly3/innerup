# 12. 下一步（建议顺序）

> 本文档为《项目规划》第 12 节 · [← 返回索引](../项目规划.md)

1. **确认仓库组织**：`fe/`（Angular 22）与 `be/`（NestJS 12）作为两个独立子项目，根 `package.json` 用 `--prefix` 转发脚本（**已落地**，没有用 workspace）。
2. 执行 **M0**：先手动跑一周，验证闭环。
3. 脚手架落地：
   - `fe/`：`npx @angular/cli@latest new fe --routing --style=scss --ssr=false`，再安装 Angular Material、ngx-echarts
   - `be/`：`npx @nestjs/cli@latest new be`（当前 NestJS 12），再装 Prisma 7、`@nestjs/swagger`、`class-validator`；数据库用**远端 PostgreSQL**（Neon / Supabase 免费版即可），把连接串写入 `be/.env`，无需 Docker、无需本地安装数据库
4. 定义[第 7 节 · 数据模型](./07-数据模型.md)的 Prisma schema 并执行首次迁移。
5. **先做 M2.5 个人档案录入**（文本 / PDF → AI 归类，见[第 13.9 节](./13-成长地图.md)），再按 M3 → M7 逐步推进；每完成一个里程碑就自用几天再继续（M4 的 prompt 要写「输入与产出交替」并带上档案快照，见[第 13.6 节](./13-成长地图.md)）。**M1 ~ M4 已落地**（M3 目标与任务、M4 AI 生成任务线，口径见[第 9 节](./09-里程碑路线图.md)），**下一步 M5 打卡与成长**。
6. 档案录入完成后，MVP 内的档案只是「用户主动填一次」；跑顺之后再上 **M8 看板** 与 **M9 自动维护**（AI 依据档案判断补输入还是补产出、从打卡自动长出，[第 13 节](./13-成长地图.md)）。

> 详细的安装 / 启动 / 环境变量说明见 [`fe/README.md`](../../fe/README.md) 与 [`be/README.md`](../../be/README.md)。
